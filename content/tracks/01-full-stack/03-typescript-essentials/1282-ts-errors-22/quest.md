# Spot the Type Error #22

Each snippet has exactly **one** line that the TypeScript compiler rejects in strict mode. Find it before you run anything. That's exactly what your editor's red squiggles do for you.

Common causes: a missing required property, assigning the wrong type, a typo in a property name, a value outside a union of literals, or using a value that might be `undefined`.
