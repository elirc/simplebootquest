# Agent Drill: Review the AI's diff #11

An agent opened a PR with this handler. Find the **most serious** problem before it ships, or confirm it's fine. Assume `requireAuth` sets `req.user`, `db` is a Prisma client, and `…Input`/`…Update` are Zod schemas.

These are the bugs AI-written handlers most often contain: missing ownership checks, mass assignment, injection, missing awaits, absent validation, leaked errors, unbounded queries, wrong status codes and logged secrets.
