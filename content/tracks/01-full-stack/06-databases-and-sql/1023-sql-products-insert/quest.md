# SQL: Insert a new product

Insert a product with id 100, `name` 'New product', `stock` 13, `price` 3, `category` 'home', `on_sale` 0. Then return how many products have that `category` as `total`.

Tables: `products` and `product_events` (open the setup to see the data). Column names in SQL are snake_case.
