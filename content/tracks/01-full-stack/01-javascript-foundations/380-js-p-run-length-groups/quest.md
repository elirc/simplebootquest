## Your task
1. `groupConsecutive(array)` groups runs of equal adjacent values: `[1,1,2,3,3,3,1]` → `[[1,1],[2],[3,3,3],[1]]`.
2. `longestStreak(days)` takes sorted `"YYYY-MM-DD"` strings (possibly with duplicates) and returns the longest run of consecutive days. That's what this app's streak feature measures!
