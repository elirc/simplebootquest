# SQL: Insert a new movie

Insert a movie with id 100, `title` 'New movie', `rating` 7.3, `year` 1980, `minutes` 82, `genre` 'sci-fi'. Then return how many movies have that `genre` as `total`.

Tables: `movies` and `movie_events` (open the setup to see the data). Column names in SQL are snake_case.
