# SQL: Insert a new car

Insert a car with id 100, `model` 'New car', `price_k` 40, `km` 0, `year` 2008, `fuel` 'diesel'. Then return how many cars have that `fuel` as `total`.

Tables: `cars` and `car_events` (open the setup to see the data). Column names in SQL are snake_case.
