# SQL: Insert a new song

Insert a song with id 100, `title` 'New song', `seconds` 351, `plays` 10, `artist` 'Kairo', `mood` 'calm'. Then return how many songs have that `artist` as `total`.

Tables: `songs` and `song_events` (open the setup to see the data). Column names in SQL are snake_case.
