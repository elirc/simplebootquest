# Practice: kebab-case

URLs and CSS class names use **kebab-case**.

## Your task
`toKebabCase(text)` converts camelCase, spaces and underscores to lowercase words joined with `-`: `"helloWorld Foo_bar"` → `"hello-world-foo-bar"`. Consecutive capitals like `"userID"` become `"user-id"`.
