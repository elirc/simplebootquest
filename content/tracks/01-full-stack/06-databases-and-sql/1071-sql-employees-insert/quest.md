# SQL: Insert a new employee

Insert a employee with id 100, `name` 'New employee', `years_at_company` 13, `salary` 42000, `level` 'junior', `team` 'platform', `remote` 0. Then return how many employees have that `level` as `total`.

Tables: `employees` and `employee_events` (open the setup to see the data). Column names in SQL are snake_case.
