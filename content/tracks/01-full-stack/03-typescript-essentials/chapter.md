---
title: TypeScript Essentials
description: Types, interfaces, unions, generics and utility types — catch bugs before your code ever runs.
---
TypeScript is JavaScript with a type system on top. The types disappear at runtime, but while you write code they catch typos, wrong arguments and missing cases. In full-stack apps they let the frontend and backend share one definition of your data.

> Note: the in-browser runner strips types and checks *behaviour*. Install TypeScript locally (`npm i -D typescript`) and run `npx tsc --noEmit` to see real type errors as you practice.
