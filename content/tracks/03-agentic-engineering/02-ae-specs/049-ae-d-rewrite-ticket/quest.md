# Write-Up: Rewrite a Vague Ticket

Here is a real-world-style ticket:

> **TODO-231: Improve the todo list**
> Users are complaining the todo list is hard to use. Make it better, add filtering and maybe sorting. Also it's slow sometimes.

Rewrite it as a spec an agent (or a new teammate) could execute without asking you anything. Where information is missing, **state your assumptions** or list the **questions** you'd ask the product owner. Split it into separate tasks if it should be.

### Include
- The goal and user value.
- Concrete, testable acceptance criteria.
- Constraints and non-goals.
- How "slow" will be measured, and the target.
- How the work is split into steps.
