AI coding agents can read your codebase, run commands, write code and open pull requests. Used well, they multiply what you can build. Used carelessly, they produce confident, plausible, **wrong** code faster than ever.

This track is about the engineering discipline of working *with* agents: giving them good specs and context, choosing the right workflow, verifying everything, and staying safe. The skills transfer to any agent (Claude Code, Cursor, Copilot, Codex, Aider…). Examples use Claude Code because this very app was built with it.

You'll answer quizzes and write **practical documents** you can reuse: a context file for your repo, specs, review checklists and team guidelines.
