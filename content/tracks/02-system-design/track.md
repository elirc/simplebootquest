System design is the art of choosing **trade-offs** on purpose. This track is practical: every chapter builds on the full-stack app you're making in the core path, and asks "what changes when 100 users become 100,000?"

You'll answer quizzes on the key concepts, and write **design documents**: the same artefact engineers write at work before building anything big. Each write-up has a rubric to review yourself against, and a reference design to compare with afterwards.
