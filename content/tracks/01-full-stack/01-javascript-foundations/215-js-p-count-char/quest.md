## Your task
1. `countChar(text, ch)` counts how many times a character appears, case-insensitively.
2. `mostCommonChar(text)` returns the most frequent **letter** (lowercased, ignoring spaces and punctuation). On a tie, return the one that appears first in the text. Return `null` if there are no letters.
