# Write-Up: Where Would an Agent Help You?

Before adopting any tool, think about **your actual work**. Take your capstone project (or your current job) and write a short audit.

1. List 6–10 recurring tasks you do (e.g. "add a CRUD endpoint", "write tests for a service", "debug a failing CI run", "update dependencies", "write a migration").
2. For each one, estimate how well an agent would do and what risk it carries, and decide on the **autonomy level** and **verification** you'd use.
3. Identify tasks you would **not** delegate (yet), and explain why.
4. Note what your repo is missing that would make agents more effective (tests? scripts? docs?).
