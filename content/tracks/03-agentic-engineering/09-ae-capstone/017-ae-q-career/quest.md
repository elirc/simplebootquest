# Growing as an Engineer in the Agent Era

What makes an engineer valuable when code is cheap to generate?

- **Judgment**: knowing *what* to build, what not to build, and which trade-offs are acceptable.
- **Specification**: turning fuzzy needs into clear, testable requirements, for humans and agents alike.
- **Verification**: knowing how to prove something works, and spotting what's wrong in plausible-looking code.
- **System thinking**: data models, failure modes, security, performance, and cost.
- **Communication**: design docs, PR descriptions, incident write-ups, and mentoring.
- **Ownership**: being the person who makes sure it actually works in production.

Concretely, as you grow from junior to mid-level and beyond: own features end to end, write the design doc before the code, review others' code (human or AI) carefully, learn the fundamentals deeply (HTTP, SQL, the browser, security), and keep a record of what you shipped and learned.
