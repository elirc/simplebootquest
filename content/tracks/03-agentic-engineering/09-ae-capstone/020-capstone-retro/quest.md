# Boss: Ship a Feature with an Agent & Write the Retro

The final quest of the track. In your capstone repository:

1. Make sure it has a good **context file** (from chapter 3).
2. Write a **spec** for a real, meaningful feature (from chapter 2).
3. Build it with a coding agent using the **explore → plan → implement → verify** workflow, with test-first for the core logic and a commit at each checkpoint.
4. **Review** the final diff as if someone else wrote it (chapter 5), and fix what you find.
5. Open a PR with an honest description.

Then write the **retrospective** here:

- The feature and the spec (summarised), with a link to the PR.
- How the session(s) went: your plan, its checkpoints, the time taken.
- What the agent did well, and where it went wrong (be specific!).
- What your verification caught.
- How you'd improve your context file, spec or workflow next time.
- What *you* learned (and whether you could build this without the agent now).
